
# نَسَق للمقاولات والتشطيبات (Nasaq Contracting & Finishing)

موقع ويب تعريفي عصري واحترافي لشركة "نَسَق" للمقاولات والتشطيبات. يهدف الموقع إلى عرض خدمات الشركة، إبراز أعمالها ومشاريعها المتميزة، وتسهيل تواصل العملاء معها.

## 🚀 المميزات (Features)

* **عرض ديناميكي للمشاريع (Portfolio):** معرض صور متكامل يوضح جودة التشطيبات المعمارية ومراحل التنفيذ.
* **واجهة مستخدم حديثة وتفاعلية (UI/UX):** تصميم متجاوب (Responsive) بالكامل، مع تأثيرات حركية (Animations) واضحة ولطيفة ومودالز (Modals) لعرض الصور.
* **السرعة والأداء:** اعتماد بنية `PHP Blocks` مجزأة (Modular) عبر استخدام الـ `Includes` لتسريع تحميل أجزاء الصفحة ولسهولة الصيانة (Header, Footer, Sections).
* **نظام تواصل آمن (Contact System):** نموذج اتصال مدمج للعملاء مع معالجة وتحقق من البيانات مدعوم بـ `PHP Mail()`.
* **صديق لمحركات البحث (SEO):** يحتوي على ملف خريطة الموقع `sitemap.xml` وهيكلة مرنة لدعم الأرشفة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **الواجهة الأمامية (Front-End Tasks):** HTML5, CSS3, Vanilla JavaScript (DOM manipulation, Modals, Lightbox).
* **الواجهة الخلفية (Back-End Tasks):** PHP (البرمجة الإجرائية - Procedural PHP).
* **تنسيق وترتيب الكود:** تقسيم صفحات الموقع باستخدام الـ `include` لتجنب التكرار.

## ⚙️ متطلبات التشغيل والتثبيت (Setup & Installation)

لأن المشروع مصمم بلغة PHP، ستحتاج إلى بيئة خادم محلي (Localhost). لإعداد المشروع محلياً:

1. **تثبيت خادم محلي:** قم بتحميل وتثبيت [XAMPP](https://www.apachefriends.org/) أو [WAMP](https://www.wampserver.com/) أو [MAMP](https://www.mamp.info/).
2. **نسخ المشروع:**
   * اذهب إلى مسار الخادم المحلي (عادة يكون `C:\xampp\htdocs` أو `C:\wamp64\www`).
   * ضع مجلد المشروع بالكامل في هذا المسار.
3. **تشغيل الخادم:**
   * افتح برنامج `XAMPP Control Panel`.
   * قم بتشغيل خدمة `Apache`.
4. **عرض المشروع في المتصفح:**
   * افتح المتصفح الخاص بك، وانتقل إلى الرابط التالي:
     `http://localhost/Before%20and%20After/` (أو اسم المجلد الذي قمت بتسميته).

## 🖨️ ملاحظة بخصوص نموذج الاتصال (Contact Form)
لكي يعمل نموذج الاتصال بشكل سليم ومثالي على الخادم المحلي، تحتاج إلى إعداد سيرفر Mail (مثل `Mailtrap` أو ضبط إعدادات الـ `php.ini` و `sendmail`). ولكنه سيعمل بشكل مباشر عند رفع المشروع على استضافة توفر خدمة الـ Email.
يمكنك تعديل البريد الإلكتروني الذي يستقبل الطلبات من داخل ملف `contact_handler.php` السطر:
```php
$to = "your-email@example.com"; 
```
